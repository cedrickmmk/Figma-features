# School App Prototype (UX/UI Design)

A mobile application prototype designed in Figma to help students track upcoming assignments, view instructions, and submit coursework.


## Prototype Link
* **Figma Prototype:** [(https://www.figma.com/design/sL4LpKktyQfwJnD996VzQW/school-app-prototype?node-id=6-147&t=kp8rD2AjH4TEe9cD-1)]

## Features
* **Dashboard Screen:** Displays the student's next class location, upcoming due dates, and a scrollable list of color-coded assignment cards.
* **Assignment Details Screen:** Shows specific assignment instructions, a file upload dropzone, a URL submission field, and a comments section.
* **Confirmation Screen:** Provides instant submission feedback with a timestamp and a summary of the submitted link and status.

## Design Process
1. **Wireframing:** Created low-fidelity wireframes to establish screen layout, hierarchy, and navigation flow across three mobile screens.
2. **Components & Assets:** Built reusable Figma components for the bottom navigation bar, primary action buttons, and assignment cards to maintain visual consistency.
3. **High-Fidelity Prototype:** Applied a cohesive color palette, typography, and interactive vertical scrolling with fixed header and navigation elements.

## Reflection

### 1. What aspects of the design process were most challenging?
The most challenging part of the design process was managing layers, alignment, and scrolling behavior across different frames. Making sure repeated shapes and text stayed organized, fixing frame heights so there were no black gaps in the mobile preview, and setting the bottom navigation bar and header to stay fixed while scrolling took careful adjustments. Learning how to edit or detach main components versus instances when making specific changes also required practice.

### 2. How did creating components and adding interactions enhance the usability of your design?
Turning reusable elements like the bottom navigation bar, primary buttons, and assignment cards into components ensured visual consistency across all three screens—the Dashboard, Assignment Details, and Confirmation screens. Adding prototype interactions transformed a static layout into a realistic, clickable user flow where a student can select an assignment, submit their work, and return to the dashboard just like in a real mobile app.

### 3. How might you use this design as a starting point for future projects?
I can use this project as a foundation by expanding the remaining navigation tabs such as building out the Schedule and Profile screens and adding more interactive states like file upload previews or error messages. Because the core buttons, cards, and navigation bar are already built as reusable components, I can also reuse this structure and color system as a template for future mobile app prototypes or showcase it in my design portfolio.
